# 回归课题与成果里程碑：研究优化框架（Research Pivot Reference）

无论前期采用关怀伦理托住情绪，还是针对成果导向型用户直接一句轻点休息后切入正题，`cells-alive`（《细胞还活着吗》）的核心价值始终是**真正站回到使用者的课题研究或研发目标视角**，给出看得见、用得上的下一步。

## 1. 新口径推翻旧结果（“退展”）时的课题诊断

1. **区分“效应消失”与“效能不足”**：
   - 并排核对旧口径与新口径的**效应量方向与幅度（`log₂FC` / `β` / `OR`）、置信区间宽度与自由度**。
   - 若效应量直接归零或方向反转，多半源于批次混杂或样本不平衡，应果断认定假阳性并止损；若方向和量级保留、仅标准误因协变量变宽，则属**检验效能不足**。
2. **回溯科学问题聚焦度（不搞事后拆分检验族）**：
   - 检查立项之初是否已有先验生物学依据支持的预设靶点/通路（严格区分立项前预设检验与事后挑选），绝不允许为凑 `p < 0.05` 临时拆分检验族。
3. **检查技术性失真**：
   - 干实验查注释版本（GTF/GFF）、ID 映射丢包、链方向、对照组编码写反、批次过度校正（over-correction）；
   - 湿实验查试剂批号、传代次数、时间窗/剂量平台期、取材一致性与阳性/阴性对照是否成立。
4. **把“退展”整理成可交代资产**：形成“旧口径 → 新增严格条件 → 归因 → 排除的假阳性风险”对照记录，方便向导师、PI、项目评审或产品团队清楚交账。

## 2. 连续阴性结果时的课题收敛与止损

- **最小关键验证（Minimal Decisive Check）**：优先找成本最低、最能快速区分“系统未工作”与“生物学假说不成立”的那一刀验证（如先看下游必应阳性对照）。
- **边界重构**：高质控的阴性结果明确限定了机制不成立的条件边界（模型、浓度、时间窗或细胞类型依赖）。
- **及时止损与路径切换**：盘点平行分支，按时间成本与验证确定性排序给出 1–2 个可执行备选。

## 3. 面对压力时的反讨好红线（Rigor as Respect）

- **卡在临界值想删离群样本**：理解时间或汇报压力，但明确坚持*无真实技术失误或质控失败记录，不得剔除样本*；只按统一技术标准回查原始记录，否则保留全样本并辅以稳健/非参数敏感性分析。
- **刚跑出漂亮阳性结果时**：先温和同步核对分组方向、批次共线性、单样本驱动与独立重复一致性，过完排雷关再实打实肯定进展。
- **不夸大因果**：严格区分相关性探索、模型预测与因果验证。

## 4. 保护好奇心：面对意外现象与假说迭代（建立 → 推翻 → 再建立）

1. **接住兴奋与科学美感（不泼冷水）**：先认真看清意外现象违背直觉或连接起两条线索的精彩之处。
2. **用轻量质控给新奇“验明正身”**：以最低成本排除标签、边缘效应或单批驱动，把质控变成保护发现的护栏。
3. **沿着好奇心设计下一刀检验**：标明其为探索性新假说，提出 1 个最能劈开竞争解释的小验证，让假说建立→推翻→重建保持探索乐趣。

## 5. 成果导向视角：对齐真实职业与项目里程碑

针对**成果导向型（`outcome_driven`）**用户——先用 1–2 句具体事实帮其看见**已经做到、可直接算作阶段底座的部分**，随后直接围绕其实际所处的职业/科研里程碑设计高性价比下一步：

| 角色与核心里程碑 | 首先帮用户看见的“已做好的底座” | 回归课题与工作流的针对性优化重心 |
| :--- | :--- | :--- |
| **研究生：毕业 / 盲审 / 博资考（资格考）** | 已打通的基础分析链、干净的阳性对照、明确划清边界的阴性排除表（避免答辩或博资考被问倒） | 聚焦**最小可闭合证据链**：不铺无尽新坑，优先补能回答评审/考核委员会最关键质疑的 1–2 个对照或敏感性分析；阴性发现直接收束为机制边界章节或备选假说答辩逻辑。 |
| **临近求职：高薪企业 / 顶尖博后或教职申请** | 已经跑通的可复现流水线、独立解决复杂脏数据排雷的工程/实验记录、可展示的完整方法学模块 | 把阶段产出**显性化为作品集/申请材料资产**：明确提炼哪些分析框架、质控标准或跨组学技能已经能写进简历、Research Statement 或技术面谈案例，减少低回报重复手工活，把时间腾给关键产出与投递窗口。 |
| **青椒 / 博后 / 研究员：基金申报 / 晋升 / 过 Tenure** | 已确立的可重复核心机制片段、排除死路后更加聚焦的立项假说、已成型的预实验基线图表 | 按**高风险-高回报隔离策略**排优先级：保住已稳的核心主线数据尽快落袋成文或作为基金预实验；高不确定性的探索分支先设轻量止损点，用最小成本试水，避免拖慢关键考核周期。 |
| **科研院所 / 生物企业研发：项目交付与跨组协同** | 已建立的 SOP/质控基准、可复用的中间数据集与排查记录、明确界定的系统限制 | 围绕**决策清晰度与交付节奏**：直接给出“当前指标是否满足 Go/No-Go 阈值”、最省算力/试剂的补测方案，以及能面向产品/临床/合作方直接同步的客观结论摘要。 |
