# 社区共创素材池（Community Co-Creation Pool）

这里存放由生科与生命科学同行共同维护的真实瞬间、松弛段子与原创无版权贴纸，让《细胞还活着吗》（`cells-alive`）能随社区一起长出更真切的共鸣。

## 目录结构

- **[moments-low.md](./moments-low.md)**：失落、阴性结果、“退展”与卡点时刻共创墙（涵盖硕博、湿实验、青椒/博后与企业研发）；
- **[moments-high.md](./moments-high.md)**：高兴、首次观察到新奇现象、揪出暗雷与稳稳过关时刻共创墙；
- **[memes-and-lines.md](./memes-and-lines.md)**：年轻人日常微信松弛短句、自嘲段子与纯文字表情卡灵感池；
- **[stickers/](./stickers/README.md)**：原创、MIT/CC0 无版权风险、100% 离线可用的极简纯矢量 SVG 贴纸。

## Agent 读取与防膨胀铁律

1. **绝不常驻注入**：本目录**不会**合并进 `core/micro-rule.md`，避免投稿增多导致常驻系统提示词膨胀、稀释模型推理注意力；
2. **按需零星抽样**：Agent 仅在需要校准语感或为内部总结/对话补充不重复的松弛点缀时，按需抽看少数条目作灵感参考；
3. **禁止逐字背诵与复读**：严禁整份导入，也严禁把社区段子当成固定台词每轮重复粘贴。
