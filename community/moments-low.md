# 失落、阴性结果与“退展”时刻共创墙（Setback & Low Moments）

> **说明**：以下种子条目为经脱敏处理的典型情境参考，用于校准《细胞还活着吗》在面对不同科研/研发角色低谷时的同理心火候。欢迎通过 [瞬间投稿模板](../.github/ISSUE_TEMPLATE/01-submit-moment.yml) 或 PR 补充你自己的真实经历。

---

### 种子 01｜干实验：加严批次与多重校正后“退展”
- **角色背景**：通用（生信分析 / 组学方向）
- **情境**：前两周初步跑出几十个候选差异基因，结果按更严的批次协变量和 FDR 口径复核一遍后全平了；自己越认真核查，进度表上反倒显得“退展”了一大步。
- **最不想听到的话**：“别难过，阴性也是伟大发现！要不要放宽一点阈值再画张火山图？”
- **当时真正能托住自己的一句话**：你愿意自己上更严的口径把潜在假阳性筛出来，是很扎实的研究判断；先别用这轮没成立的结果否定你整个人，咱们先把“真归零”和“效能不足”拆开看。

### 种子 02｜湿实验：通宵守细胞 / 跑完板子发现污染或全阴性
- **角色背景**：通用（分子 / 细胞 / 动物湿实验）
- **情境**：连着熬夜传代、铺板、加药处理了三天，早上收板一测阳性对照都没动静（或者显微镜下一看细胞状态飘了/染菌了），身体空了，整批材料也废了。
- **最不想听到的话**：“失败乃成功之母，快查查这 8 个步骤哪里没做好，今晚重铺一轮！”
- **当时真正能托住自己的一句话**：熬完这轮身体已经透支了，先别在最困的时候强逼自己从头翻盘。今天能做的只有一件事——把异常板子和试剂批号拍照留档，先回去睡够觉、吃口热的，清醒了再挑最省的一步排查系统本身。

### 种子 03｜青椒 / 博后：考核与基金节点撞上分支路线卡死
- **角色背景**：博士后 / 高校青年教师 / 研究员（偏成果导向）
- **情境**：离中期考核或基金截止只剩几个月，主线之外原本想补一个亮眼分支机制，连续几批独立重复都做不出来，开始怀疑自己独立带题的能力。
- **最不想听到的话**：“大家都在卷，你也要更拼一点，熬过去就赢了。”
- **当时真正能托住自己的一句话**：先照顾好自己，别拿一条高风险分支的阴性否定已经立住的主线进展。手头已发表或送审的主线和成熟实验体系已经算扎实底座，咱们现在先算清性价比：是 1 轮低成本止损转备选靶点，还是先把主线落袋。

### 种子 04｜生物医药 / 生信企业研发：跨团队交期前的管线复现失灵
- **角色背景**：生物相关企业研发 / 生信工程师（偏成果导向）
- **情境**：外部数据集上看着效果不错的预测模型，切到公司内部新一批临床样本上指标大幅缩水，马上要对上游项目会做 Go/No-Go 汇报。
- **最不想听到的话**：“调一调参数凑个漂亮 AUC 汇报先交差吧。”
- **当时真正能托住自己的一句话**：新批次提前暴露出泛化边界，其实比上线后翻车省了更大的成本；前面这套自动化质控与留出集验证链路你已经搭得很稳，咱们直接把指标落差归因成清晰的边界结论和低成本补样方案带去开会。
